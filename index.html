Under the hood

How the mesh works

When you send a message, Open Text finds the best path — one device at a time — so nothing gets sent twice.

📱
💻
📲
📺
⌚
🖥️
1

Device discovery

Open Text scans for nearby devices over Bluetooth and Wi-Fi, building a live map of your personal mesh network.

2

Capability check

The current device checks if it has SMS, RCS, or iMessage capability. If it does, it sends directly using the native method.

3

Fallback routing

If this device can't send, it hands off to the next device in the mesh — one at a time, no duplicates, until it succeeds.

4

Instant sync

Once sent, the message state syncs back across all connected devices so every screen shows the same thread in real time.
